# 시연 영상 발표용 부연 설명 v1.0

## 1. 개요

### 1.1 목적

발표 때 시연 영상(06, 약 3분 46초)을 틀면서 내레이션만으로는 전달되지 않는 **왜 그렇게 만들었는지, 무엇을 확인했는지**를 덧붙이기 위한 발표자용 대본이다. 장면마다 영상 시각, 화면, 내레이션, 덧붙일 말을 나란히 적었다.

### 1.2 쓰는 법

| 방법 | 언제 |
|---|---|
| A. 영상을 끝까지 틀고, 끝난 뒤 3장 '핵심 부연 5가지'만 말한다 (약 1분) | 발표 시간이 5분 이하일 때 (권장) |
| B. 표시한 ★ 장면에서 영상을 잠깐 멈추고 '덧붙일 말'을 한다 (약 2분 추가) | 발표 시간이 7분 이상일 때 |
| C. 질문이 나오면 4장 '예상 질문과 답'을 쓴다 | 질의응답 |

### 1.3 영상과 시스템 바로가기

| 항목 | 주소 |
|---|---|
| 시연 영상 | https://jiwon2324.github.io/TODAK-SmartFarm/Demo/ (과제 폴더 `06_시연영상_TODAK_4K.mp4`) |
| 로그인 없이 둘러보기 | https://jiwon2324.github.io/TODAK-SmartFarm/app/demo |
| 소스 코드 | https://github.com/jiwon2324/TODAK-SmartFarm |

### 1.4 시작 전에 한 문장으로 밝힐 것

"영상의 하우스 센서 값은 가상 센서 시뮬레이터가 만든 값이고, 외부 기상은 기상청 양평 관측소 실측 자료입니다. 내레이션은 대본을 음성 합성으로 읽힌 것입니다." — 데이터 출처와 음성 합성 사용을 먼저 밝혀 두면 질문에서 오해가 생기지 않는다.

## 3. 영상이 끝난 뒤 — 핵심 부연 5가지 (약 1분)

1. **실장비 없이 검증했지만 같은 규격이다.** 시뮬레이터는 실제 게이트웨이와 같은 MQTT 주소·데이터 형식으로 값을 보내고 명령에 응답한다. 실장비를 붙여도 서버와 웹은 그대로 쓴다.
2. **명령과 실제 상태를 나눴다.** 장치가 실행을 확인해야 상태가 바뀌고, 응답이 없으면 경보가 난다.
3. **통신이 끊겨도 현장은 안전하다.** 게이트웨이가 마지막 기준값 사본으로 안전 운전을 하고, 복구 뒤 모아 둔 측정값을 다시 보낸다.
4. **권한은 서버에서 검사한다.** 화면에서 버튼을 숨기는 것만으로는 막히지 않기 때문이다.
5. **운영까지 준비했다.** 영상 이후에 통합 관제 화면, 운영 점검 화면, GA4 이용 통계, 운영 매뉴얼과 설치 보고서를 더해 운영팀에 넘길 수 있게 했다 (08·09·11 문서).

## 4. 예상 질문과 답

| 질문 | 답 |
|---|---|
| 실제 센서 값이 아니면 의미가 있나? | 이번 사업 범위는 B안(시뮬레이터 검증)이다. 고온·저온·통신 단절처럼 실제로 일부러 만들기 어려운 상황을 반복 시험할 수 있다는 장점이 있고, 외부 기상은 실측 자료를 썼다 |
| 영상 속 시간은 실제 시간인가? | 시나리오 결과를 기다리는 1~3분만 줄였다. 나머지는 실제 조작 화면이다 |
| 내레이션 목소리는 누구인가? | 대본을 음성 합성으로 읽힌 것이다. 대본과 화면은 직접 만들었다 |
| 자동 제어가 잘못 동작하면? | 안전 한계(35℃·5℃)가 수동·자동보다 우선하고, 장치마다 최소 작동 시간·하루 최대 횟수 제한이 있다. 실장비 적용 첫 1주는 '알림만' 모드로 운영하도록 계획했다 |
| 통신이 끊기면 데이터는? | 게이트웨이가 모아 두었다가 복구 뒤 다시 보낸다. 같은 값이 두 번 와도 메시지 ID로 한 번만 저장한다 |
| 왜 이 프레임워크를 썼나? | 화면 React, 서버 Spring Boot, 통신 MQTT. 자세한 이유와 버전은 11 바이브 코딩 기록 4장 |
| AI를 어떻게 썼나? | 코드와 문서 초안은 AI(Claude Code)가 쓰고, 범위 결정·시험·설치·화면 확인은 직접 했다. 확인 단계에서 AI가 쓴 문구 오류와 설치 결함을 찾아 고쳤다 (11 문서 3장) |

## 5. 결론

영상은 '무엇이 되는지'를 보여 주고, 이 부연 설명은 '왜 그렇게 만들었고 어떻게 확인했는지'를 채운다. 발표 시간이 짧으면 영상 + 3장 핵심 5가지, 길면 ★ 장면 멈춤 설명을 더하고, 질문은 4장으로 답한다.
